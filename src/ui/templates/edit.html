{% extends "base.html" %} {# The Edit tab: hand-trim one chapter before Render cuts and stitches it. # State, and the one rule this pane bends Every other pane here is stateless by design — Rust re-renders it whole, so it cannot disagree with the files (see `ui::web`). This one keeps a working copy of the keep-list in JavaScript, because a repaint reloads the page, and reloading mid-edit would throw away the zoom level, the scroll position and the playhead every time you dropped a segment. An editor that loses your place on every click is not usable. What that rule protects is kept anyway: every committed change posts the *whole* span list to Rust immediately, which normalises and writes it. There is no unsaved state and no delta to lose — a dropped message costs the last action, never the file. Rust repaints on three events only: opening another chapter, Reset, and a finished render. # The model One list of kept spans, in source milliseconds. Dropped time is the gap between them. Dragging over the waveform, clicking a segment and clicking words all build the same thing — a time selection — and Keep / Drop act on it. Nothing else to learn. #} {% block content %}
