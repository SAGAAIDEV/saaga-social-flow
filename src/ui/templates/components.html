{# Reusable pane components. Every macro takes plain data and emits markup plus, where it acts, a `data-send` payload. That attribute is the whole contract with `ui::web`: the delegated click handler in base.html reads it, JSON-encodes it, and Rust parses it into a `WebEvent`. A component never names a JavaScript function, so adding one cannot break another. #} {# A button that posts `payload` when clicked. #} {% macro action(label, payload, primary=false, disabled=false) %} {% endmacro %} {# A checkbox whose change posts `payload` with the new value appended. #} {% macro toggle(label, checked, payload) %} {% endmacro %} {# A small pill. `tone` is one of ok / bad / warn, or omitted for neutral. #} {% macro tag(text, tone="") %} {{ text }} {% endmacro %} {# A bulleted list, or nothing at all when empty — an empty heading reads as a finding of "none", which is not the same as having nothing to say. #} {% macro bullets(title, items) %} {% if items %}

{{ title }}

    {% for item in items %}
  • {{ item }}
    • {% endfor %}
{% endif %} {% endmacro %} {# A rendered line diff. `changes` is a list of {kind, text} where kind is same / add / del / skip. Colour is what makes a deletion visible; the native pane could only ever show this as plain text. #} {% macro diff(changes) %} 
{% for change in changes %}{{ change.text }}{% endfor %}
{% endmacro %} {# A card wrapping one reviewable item. #} {% macro card() %}
{{ caller() }}
{% endmacro %}
